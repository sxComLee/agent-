flowchart TD
      %% 系统初始化阶段
      Start([系统启动]) --> Init[初始化阶段]
      Init --> Config[加载配置文件]
      Config --> Env[设置环境变量]
      Env --> Tools[注册15类工具]
      Tools --> Memory[初始化3层记忆架构]
      Memory --> Queue[创建h2A消息队列]
      Queue --> Listener[启动Steering监听器]

      %% Agent核心引擎初始化
      Listener --> AgentCore[实例化AgentCore]
      AgentCore --> SetupContext[设置执行上下文]
      SetupContext --> Ready([系统就绪])

      %% 用户请求接收阶段
      Ready --> WaitInput[等待用户输入]
      WaitInput --> UserInput([用户输入])
      UserInput --> ParseMessage[消息解析]
      ParseMessage --> Validate[输入验证]

      %% 上下文预处理阶段
      Validate --> CheckMemory[内存使用率检查]
      CheckMemory --> CheckThreshold{92%阈值判断}
      CheckThreshold -->|超过| Compress[触发AU2压缩]
      CheckThreshold -->|未超过| Continue[继续处理]

      %% 消息压缩处理
      Compress --> AU2[8段式结构化压缩]
      AU2 --> UpdateContext[更新上下文]

      %% 主循环启动
      Continue --> MainLoop[启动nO主循环]
      UpdateContext --> MainLoop

      %% 请求处理阶段
      MainLoop --> StreamStart[发送stream_start事件]
      StreamStart --> SystemPrompt[生成系统提示]
      SystemPrompt --> LLMCall[调用语言模型]

      %% 实时Steering检查
      MainLoop -.->|并行| SteeringCheck[检查实时输入]
      SteeringCheck -->|有新输入| Inject[注入到消息流]

      %% 工具调用处理
      LLMCall --> ToolDecision{需要工具调用?}
      ToolDecision -->|是| ToolProcess[工具处理流程]
      ToolDecision -->|否| DirectResponse[直接响应]

      %% 工具处理详细流程
      ToolProcess --> ToolDiscovery[工具发现与验证]
      ToolDiscovery --> ToolValidate[参数验证]
      ToolValidate --> PermissionCheck[权限检查]
      PermissionCheck --> ConcurrencyCheck[并发安全检查]

      %% 并发处理
      ConcurrencyCheck --> UH1调度[UH1调度器]
      UH1调度 -->|并发安全| Parallel[并行执行]
      UH1调度 -->|非并发安全| Sequential[串行执行]

      %% SubAgent处理
      Parallel -->|Task工具| SubAgent[启动I2A SubAgent]
      SubAgent --> SubLoop[独立nO循环]
      SubLoop --> SubTools[SubAgent工具执行]
      SubTools --> SubResult[返回结果]

      %% 工具执行结果
      Parallel --> MH1[MH1工具引擎]
      Sequential --> MH1
      MH1 --> ToolExecute[具体工具执行]
      ToolExecute --> ToolResult[生成结果]

      %% 结果处理
      ToolResult --> ResultFormat[格式化结果]
      SubResult --> ResultFormat
      DirectResponse --> ResultFormat

      %% 继续判断
      ResultFormat --> ContinueLoop{继续循环?}
      ContinueLoop -->|是| MainLoop
      ContinueLoop -->|否| Cleanup[清理阶段]

      %% 清理阶段
      Cleanup --> SaveState[保存会话状态]
      SaveState --> UpdateMemory[更新长期记忆]
      UpdateMemory --> ReleaseResources[释放资源]
      ReleaseResources --> End([系统退出])

      %% 错误处理分支
      ToolExecute -->|异常| ErrorHandler[错误处理]
      ErrorHandler --> Fallback[降级处理]
      Fallback --> Cleanup

      %% 中断处理分支
      SteeringCheck -->|中断信号| AbortProcess[中止当前处理]
      AbortProcess --> Cleanup

      %% 内存溢出处理
      CheckMemory -->|内存溢出| MemoryOverflow[内存溢出处理]
      MemoryOverflow --> EmergencyCompress[紧急压缩]
      EmergencyCompress --> Continue

      %% 样式定义
      classDef initClass fill:#e1f5fe,stroke:#01579b
      classDef processClass fill:#fff3e0,stroke:#e65100
      classDef toolClass fill:#f3e5f5,stroke:#4a148c
      classDef errorClass fill:#ffebee,stroke:#c62828
      classDef decisionClass fill:#e8f5e8,stroke:#2e7d32

      class Start,Ready,End initClass
      class MainLoop,LLMCall,ToolProcess processClass
      class ToolDiscovery,MH1,SubAgent toolClass
      class ErrorHandler,MemoryOverflow errorClass
      class CheckThreshold,ToolDecision,ContinueLoop decisionClass

  这个Mermaid流程图完整展现了Claude Code Agent系统的生命周期，包括：

  1. 系统初始化：从启动到就绪的完整流程
  2. 请求处理：从用户输入到响应输出的全链路
  3. 核心技术组件：h2A队列、nO主循环、AU2压缩、UH1调度器等
  4. 并发处理：SubAgent启动和工具并发执行
  5. 异常处理：错误恢复、内存溢出、中断信号处理
  6. 资源清理：会话状态保存和系统退出

  每个阶段都基于我们逆向分析的真实技术实现，准确反映了Claude Code v1.0.33的完整工作流程。
