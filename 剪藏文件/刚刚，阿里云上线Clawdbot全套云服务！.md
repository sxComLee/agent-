# 刚刚，阿里云上线Clawdbot全套云服务！

## 核心亮点

阿里云百炼（Coding Plan）正式上线 OpenClaw（原Clawdbot）一键部署服务。

### 价格

- **首购**：低至7.9元
- **续费**：5折起
- **性价比**：约20-40元/月，比买Mac Mini省几千元

### 支持的国内模型

- Qwen3.5、Qwen3-max、Qwen3-coder
- GLM-5、GLM-4.7
- Kimi-k2.5

## 部署步骤

### 步骤一：购买服务器

1. 访问阿里云百炼：https://t.aliyun.com/U/0iiOuy
2. 选择轻量应用服务器
3. 配置：**至少2核2G**
4. 地区：**新加坡/香港**（避免大陆访问海外AI API的网络问题）
5. 选择 **OpenClaw/Clawdbot镜像**

### 步骤二：登录服务器

通过控制台SSH登录，或扫码登录轻量服务器控制台。

### 步骤三：配置OpenClaw

```bash
clawdbot onboard
```

按向导完成：
- 模型选择（推荐GLM-4.7或Kimi）
- API Key填写
- 通道配置（飞书/钉钉/企微等）

### 步骤四：持久化运行

```bash
nohup clawdbot gateway --port 18789 --verbose > /tmp/clawdbot-gateway.out 2>&1 & disown
```

## 为什么选择云部署

| 方案 | 成本 | 安全性 | 便利性 |
|------|------|--------|--------|
| 主力机本地 | 免费 | ❌低（高权限风险） | ✅高 |
| 旧电脑/Mac Mini | 一次性购买 | ✅隔离 | ✅高 |
| 云服务器 | 20-40元/月 | ✅最佳隔离 | ✅7x24 |
| 虚拟机 | 免费 | ✅较好 | ⚠️性能受限 |
