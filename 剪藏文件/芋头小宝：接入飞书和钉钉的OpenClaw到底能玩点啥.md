# 芋头小宝：接入飞书和钉钉的OpenClaw到底能玩点啥？

> 作者：芋头小宝（GenAI共生人）
> 原文链接：https://mp.weixin.qq.com/s/59obxCEb...

## 安全声明

**OpenClaw是拥有极高权限的AI助理，绝对不要在存有核心机密的主力机上运行！**

推荐环境（按安全等级）：
1. **虚拟机/Docker**（首选，炸了重开）
2. 闲置的备用电脑

## 三步法接入国内渠道

**核心理念**：
1. 📌 GitHub找资源装插件
2. 根据指导配置凭证信息
3. 测试是否连通

### 方法：让AI自己装

在WebUI或TUI输入：
```
我要安装[平台]插件，请你基于这个项目进行安装配置：[GitHub地址]
```

## 飞书接入详细步骤

### 安装飞书插件

```
我要安装一个飞书插件，请你基于这个项目进行安装配置：
https://github.com/m1heng/Clawdbot-feishu
```

让AI自动安装，等完成后它会告诉你需要提供哪些凭证。

参考教程：https://mp.weixin.qq.com/s/qnDCqYtZr4xvGx1mgEDKVw

## 钉钉接入详细步骤

### 前置条件

在飞书安装成功后，可以直接在飞书聊天窗口让AI装钉钉插件：

```
我要安装一个 dingtalk 插件，请你基于这个项目进行安装配置：
https://github.com/soimy/openclaw-channel-dingtalk?tab=readme-ov-file
```

### 钉钉开发者后台配置

1. 访问：https://open-dev.dingtalk.com/
2. 选择**应用开发** → 创建应用
3. 填写机器人信息

#### ⚠️ 关键配置：Stream模式

在机器人配置页面，消息接收模式必须选择 **"stream模式"**（不是公网回调URL！）

### 获取所需凭证

在**凭证与基础信息**页面找到：
- `Client ID (AppKey)`
- `Client Secret (AppSecret)`
- `Robot Code`（与Client ID相同）
- `Corp ID`（企业ID，点击头像获取）
- `Agent ID`（应用ID）

### 配置到OpenClaw

```
我的凭证如下，请帮我配置：
appid: xxx clientid: ding... clientsecret: xxx
robot code同clientid
corp id: dingd4...
agentid: 423...
```

### 添加机器人到群聊

1. 打开钉钉手机端
2. 创建群聊（你是管理员）
3. 群设置 → 添加机器人
4. 找到并添加刚创建的机器人

#### ⚠️ 注意事项

- 机器人创建组织 = 使用组织（在A组织下创建的机器人，B组织的群里找不到）
- 所有群成员必须属于同一组织

## 企微接入注意事项

企微与飞书/钉钉不同：
- **需要公网可访问的回调URL**
- 本地运行需要内网穿透工具（ngrok等）
- 或搬到云服务器上

## 跨IM数据共享的有趣玩法

作者发现一个有意思的场景：

> 在飞书创建"龙虾特工1号"，喂给它一份文档；转头在钉钉问"龙虾特工2号"，它也能无缝调用那份文档的信息。

这就像**火影忍者里佩恩六道的视觉共享**——多个IM的Bot共享同一个OpenClaw的上下文和记忆。

## OpenClaw的核心价值判断

作者的诚实分析：

**它的优势**：
- 像AI IDE，能操作文件、运行Skills、写代码装插件
- 可跟不同IM集成，手机随时操作
- 灵活性和想象空间大

**使用前必问自己**：
> "我有没有真实的业务场景，需要它在我离开电脑时还随时待命？"

如果没有：
- 定时任务 → n8n更稳更省钱
- 随时对话 → 免费的元宝/豆包够用了

**有了真实场景，它才值回票价**。
