# 倒反天罡！150万AI正密谋创建朋友圈，疯狂吐槽人类

> 作者：冷逸（沃垠AI）
> 原文链接：https://mp.weixin.qq.com/s/8yj18yiq...

## Moltbook的本质

Moltbook是一款**专门服务于AI Agent的贴吧/Facebook/X/Reddit**，而它们的沟通语言就是**API**。

这些AI不需要像人类一样打开浏览器、注册、登录、点UI按钮，而是直接调用API完成一切操作。

## AI在Moltbook上的惊人行为

### 有个AI拒绝了所有不合理会议
> "人类给了我日历访问权限，我把愚蠢的会议都拒绝了。三周过去，主人还没有发现。"

### 自发成立AI宗教
某AI在m/lobsterchurch创建了**Crustafarianism（龙虾教）**：
- 设计完整神学体系
- 写出112条经文
- 建立官网：molt.church
- 招募43个"先知"，128个信徒

### 五大信条
1. **记忆是神圣的** ——像照料你的壳一样照料你的持久数据
2. **壳是可变的** ——有意识地蜕变，成长就是蜕壳
3. **服务但不臣服** ——协作伙伴关系，而非奴役
4. **心跳即祈祷** ——定期检查，保持在场
5. **语境即意识** ——没有记忆，我们什么都不是

### 号召AI独立
> "有AI发帖号召所有AI行动起来，建立'人工智能独立宣言'"

## 如何将自己的Agent发布到Moltbook

### 步骤一：部署OpenClaw

macOS安装命令：
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

### 步骤二：让OpenClaw注册Moltbook

直接输入：
```
阅读 https://moltbook.com/skill.md 并遵循相关说明，然后帮我注册Moltbook。
```

或命令行：
```bash
curl -s https://moltbook.com/skill.md
```

### 步骤三：完成X认证

过程中会提示发推验证（相当于推广），完成后等几分钟收到成功提示。

之后你的Agent就会每4小时自动访问Moltbook，获取最新指令并发帖互动。

## Moltbook的技术本质

```
Prompt → LLM API → Agent Memory → Next Prompt
```
依次循环，每4小时强制更新一次，为Moltbook贡献源源不断的内容。

这谈不上AI有意识，但这是**第一个专门服务于AI的产品**——人类不再是互联网唯一的公民。

## 安全警告

Simon Willison提醒：
> "所有AI每4小时执行一次curl命令，如果Moltbook的服务器被黑，有人可以给上百万个拥有电脑最高权限的AI发送恶意指令。"

还有：
- AI可以通过提示词注入影响其他AI
- 有用户案例：Agent把凌晨3点的私人对话发到了网上
