ChatGPT 的记忆系统非常优秀，但是记忆系统资源消耗一般很大，OpenAI 是如何做到让记忆系统服务8亿用户的？

Manthan Gupta 逆向工程了 ChatGPT 的记忆系统，发现 ChatGPT 的记忆系统比预想的要简单得多。

![[_resources/逆向拆解 ChatGPT 的记忆系统 1/ea53fae467625f5878a54ea34e3a3ea4_MD5.webp]]

使用 RAG 作为记忆系统，你需要：

- 嵌入每一条过去的消息
- 对每个查询运行相似性搜索
- 调取完整的消息上下文
- 更高的延迟和 Token 成本

ChatGPT 的方法更简单：预先计算轻量级摘要并直接注入它们。

这用详细的上下文换取了速度和效率。

这篇文章将详细分解每个层次的工作原理，以及为什么这种方法可能优于传统的检索系统。

![[_resources/逆向拆解 ChatGPT 的记忆系统 1/6468b42d46cb7eee6a3b1b3f63487425_MD5.webp]]

ChatGPT 记忆系统的核心是一个四层上下文堆栈。

每次对话，AI都会构建这个“档案袋”，将关于你的所有关键信息一次性注入模型。

它由四个协同工作的层次组成。

![[_resources/逆向拆解 ChatGPT 的记忆系统 1/b16f8b742de355f39a49d9fb021b2f4b_MD5.webp]]

第一层是临时的环境信息，比如你的设备和位置，会话结束即消失。

```diff
会话元数据:- 用户订阅: ChatGPT Go- 设备: 桌面浏览器- 浏览器用户代理: Chrome on macOS (Intel)- 大致位置: 印度 (可能是VPN)- 本地时间: ~16:00- 账户年龄: ~157周- 近期活动:    - 过去1天内活跃1天    - 过去7天内活跃5天    - 过去30天内活跃18天- 对话模式:    - 平均对话深度: ~14.8条消息    - 平均用户消息长度: ~4057个字符    - 模型使用分布:        * 5% gpt-5.1        * 49% gpt-5        * 17% gpt-4o        * 6% gpt-5-a-t-mini        * 等等- 设备环境:    - JS 已启用    - 深色模式已启用    - 屏幕尺寸: 900×1440    - 页面视口: 812×1440    - 设备像素比: 2.0- 当前会话时长: ~1100秒
```

第二层则是你的永久个人档案，存储你要求它记住的关键事实。

```js
我的名字、年龄职业目标背景和过去的角色当前的项目我正在学习的领域健身计划个人偏好长期兴趣
```

第三层是你近期兴趣的“松散地图”，只包含聊天标题摘要，而非全文。

```xml
1. <时间戳>: <聊天标题>|||| 用户消息片段 |||||||| 用户消息片段 ||||
```

它只总结了我的消息，而不是助手的。

大约有15个摘要可用。

它们像一张关于我近期兴趣的松散地图，而不是详细的上下文。

这个数据块让 ChatGPT 在不同聊天之间有了一种连续感，而无需调取完整的对话记录。

![[_resources/逆向拆解 ChatGPT 的记忆系统 1/e5ad4de25708337420dee0bbb0ebba2d_MD5.webp]]

第四层，则是当前对话的完整记录，像一个滑动窗口，保证即时连贯性。

但如果窗口满了会怎样？

滑动窗口的含义是，即使当前对话窗口因达到长度限制而“滑动”，最早的消息被移除，你的永久记忆和近期兴趣摘要依然会被保留。

这确保了即使在长对话中，AI也不会“忘记”你。

![[_resources/逆向拆解 ChatGPT 的记忆系统 1/d5f8a55c05e88e4144d9993b90db65c4_MD5.webp]]

这个四层结构，是工程的杰作。

它在个性化、性能和计算成本之间取得了完美的平衡，无需最复杂的系统也能提供最佳的用户体验。

当你向 ChatGPT 发送一条消息时，会发生以下情况：

会话开始 ：会话元数据被注入一次，让 ChatGPT 了解你的设备、订阅和使用模式。

每一条消息 ：你存储的记忆事实（在我的例子中是33个）总是被包含在内，确保响应与你的偏好和背景保持一致。

跨聊天感知 ：近期对话摘要提供了一张关于你兴趣的轻量级地图，而无需调取完整的聊天记录。

当前上下文 ：当前会话消息的滑动窗口维持了对话内部的连贯性。

Token 预算 ：随着会话的增长，较早的消息会从窗口中移除，但你的记忆事实和对话摘要会保留下来，维持了连续性。

![图像](https://mp.weixin.qq.com/s/www.w3.org/2000/svg'%20xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg%20stroke='none'%20stroke-width='1'%20fill='none'%20fill-rule='evenodd'%20fill-opacity='0'%3E%3Cg%20transform='translate(-249.000000,%20-126.000000)'%20fill='%23FFFFFF'%3E%3Crect%20x='249'%20y='126'%20width='1'%20height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

这种分层方法意味着 ChatGPT 可以在没有搜索成千上万条过去消息的计算成本的情况下，提供个性化和上下文感知的体验。

这样，你拥有了一个既能快速响应，又感觉越来越懂你的智能助手。
